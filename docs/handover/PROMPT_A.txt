RULES THAT ARE NOT NEGOTIABLE:
- Nothing secret is ever committed. There is no build step: Cloudflare Pages
  publishes the repo root verbatim and the GitHub repo is public, so every
  committed file is a public URL. This rule was broken twice on 2026-09-16/17;
  read A1 before you do anything else.
- Migrations are immutable once committed (scripts/check-migration-immutability.mjs).
  There is exactly one documented exception; read its header before adding a
  second.
- A green test run is not a deploy. Nothing in CI applies migrations to
  production — `supabase db push --linked --yes` does, by hand. Confirm with
  `supabase migration list --linked`, never with a doc.
- Browser checks never touch production: installMockCloud() before goto(),
  resolveLocalOnlyTarget() for the target, never TARGET_URL.
