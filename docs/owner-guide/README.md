# מדריך לבעל המועדון

`haimunia-owner-guide.pdf` — 9 עמודים, עברית, מיועד למי שרואה את האפליקציה
בפעם הראשונה.

## לבנות מחדש

```
cd scripts/browser-check
node make-owner-guide-shots.mjs   # מצלם מחדש את המסכים
node make-owner-guide-pdf.mjs     # מרנדר את ה-PDF
```

## על התמונות

כל התמונות ב-`shots/` צולמו מול **שרת מקומי עם נתונים מומצאים**.
`resolveLocalOnlyTarget()` מסרב לכל יעד שאינו מקומי, ו-`installMockCloud()`
חוסם כל בקשה ל-supabase.co — כך שאף שם, אימון או מספר אמיתי של המועדון
לא יכול להגיע לקובץ.

הנתונים במסכי ההתקדמות ולוח השנה נרשמו דרך ה-UI האמיתי (`logSomeSets`)
ולא צוירו: מסך התקדמות ריק לא מלמד דבר על מה המסך עושה.

## לעדכן את התוכן

עורכים את `guide.html` ומריצים מחדש את `make-owner-guide-pdf.mjs`.
טבלת ההרשאות בעמוד 8 נגזרה מ-`role_permissions` בפועל — אם ההרשאות
משתנות, צריך לעדכן אותה ידנית.
