# WhatsApp message for the first friends

Copy, replace `<הקישור>` with a circle invite link (Circle, **הזמנה**, **שיתוף**;
the link lives 7 days). Send it to each friend one by one, not in a group, so
nobody else can use the link: it admits up to 5 people.

```

זה בחינם ופרטי: אין פרסומות, אין מייל ואין טלפון, והיומן שלך נשאר רק אצלך בטלפון.

הצטרפות מהקישור (עדיף לפתוח ב-Safari או Chrome, לא בתוך וואטסאפ). הקישור תקף 7 ימים:

```
